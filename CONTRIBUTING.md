## 💎 Contributor Rewards & Commercial Revenue Share

Sialki Labs operates on an **Open-Core Model**:
* **Community Edition (100% MIT Open Source)**: Free forever for local developers, researchers, and creators.
* **Sialki Enterprise Cloud (Commercial)**: Hosted, multi-tenant enterprise gateways and DAW plugins.

### Contributor Benefits:
1. **Official Authorship Credit**: Featured in `AUTHORS.md`, `README.md`, and all release notes.
2. **Maintainer Status**: Core contributors earn write access and official `@SialkiLabs` maintainer badges.
3. **Commercial Revenue Share**: Active maintainers who contribute to core infrastructure receive a formal, contract-backed percentage share of commercial license revenue generated by Sialki Enterprise products.

## 🛠️ How to Get Started

1. **Fork the Repository**:
   Click the **Fork** button at [https://github.com/SialkiLabs/Suno-Hmnn-MCP](https://github.com/SialkiLabs/Suno-Hmnn-MCP).

2. **Set Up Local Development Environment**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Suno-Hmnn-MCP.git
   cd Suno-Hmnn-MCP
   pip install -r requirements.txt
   playwright install chromium
   ```

3. **Pick an Issue**:
   Check our open [GitHub Issues](https://github.com/SialkiLabs/Suno-Hmnn-MCP/issues) tagged with:
   * `good first issue` — Great for new contributors.
   * `help wanted` — High-priority features needing experienced engineers.
   * `bounty` — Issues eligible for financial rewards or grant allocations.

4. **Submit a Pull Request**:
   * Keep PRs focused on a single feature or bug fix.
   * Ensure code follows PEP 8 conventions.
   * Provide clear descriptions and test instructions in your PR.
