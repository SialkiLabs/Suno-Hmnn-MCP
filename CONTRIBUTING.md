# Contributing to Suno-Hmnn-MCP

Suno-Hmnn-MCP is an MIT-licensed project developed by Sialki Labs. Contributions should improve a specific workflow, correct a reproducible defect, or make the documentation more accurate.

## Discuss the scope

Use [Issues](https://github.com/SialkiLabs/Suno-Hmnn-MCP/issues) for bugs and focused proposals. Discuss substantial architecture or authentication changes with the maintainers before implementation. Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not post cookies, tokens, private audio, personal information, or account identifiers in public issues. Report vulnerabilities through [SECURITY.md](SECURITY.md).

## Set up development

```bash
git clone https://github.com/YOUR_USERNAME/Suno-Hmnn-MCP.git
cd Suno-Hmnn-MCP
pip install -r requirements.txt
playwright install chromium
```

Use an account you are authorized to access. Keep `.env`, downloaded content, local databases, and credentials outside commits.

## Submit a focused pull request

- Explain the problem, the proposed behavior, and the affected tools.
- Keep unrelated changes separate.
- Include reproduction steps and relevant tests or manual verification instructions.
- State what was and was not tested, including any service or plan requirements.
- Preserve existing license notices and identify third-party material.
- Do not introduce unsupported security, compatibility, or performance claims.
